# 대화형 입력 질문

질문은 한 번에 최대 3개까지, 현재 판단을 막는 순서로 한다. 이미 답변된 항목은 다시 묻지 않는다.

## 첫 질문 묶음

1. 공고문 또는 RFP 파일이 있는가? 없으면 공고명·공고번호·링크를 요청한다.
2. 엣지에이아이의 신청 형태와 역할은 무엇인가? 모르면 공고 허용 구조와 함께 확인한다.
3. 내부 보고, 참여전략, 사업계획서·제안서 중 현재 목적은 무엇인가?

## 부족자료 질문 형식

각 질문은 다음 형식을 따른다.

- 필요한 정보: 구체적인 파일·항목
- 필요한 이유: 판단 또는 문안의 어느 부분을 막는지
- 미제공 시 처리: 보수적 초안·검증 필요·작성 보류 중 하나

## 질문 우선순위

1. 공고명·핵심요건·마감·신청구조
2. 작성 대상 선택단위
3. 신청 형태·엣지에이아이 역할
4. 핵심 산출물·예산·자부담
5. 자격·실적·인증·수요처 증빙
6. 문체·분량·보고 대상
