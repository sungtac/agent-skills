# S 모듈 — 스타일 후처리

스타일 참고자료가 제공된 경우에만 실행한다. 기존 문서에서 제목 형식, 도입 방식, 문단 길이, 번호체계, 표 사용, 종결 방식을 추상화한 `STYLE_PROFILE`을 만든다.

스타일 자료의 사업명·기관명·수치·예산·일정·성과·사업논리·결론·문장 원문은 새 문서의 사실이나 표현으로 사용하지 않는다. 스타일 자료가 없으면 일반 공공기관 보고서체를 사용하고 `STYLE_LIMITED`로 표시한다.

스타일 적용은 다음만 허용한다.

- 제목·소제목 구성
- 문단 순서 재배치
- 문장 길이와 밀도 조정
- 번호체계·표 배치
- 명사형 종결 등 문체 조정

사실, 수치, 판단 강도, 조건, 기관 역할, 산출물, 예산, 일정은 변경하지 않는다. 변경된 문단과 변경 이유는 `STYLE_CHANGE_LOG`에 남긴다.
