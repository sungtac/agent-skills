# D 모듈 — 실제 문안 작성

## 목적

`STRATEGY_PACKET`, 작성양식, 평가기준, 최종 사용 가능 주장을 바탕으로 사업계획서·제안서·검토보고서 문안을 작성한다.

## 작성 전 확인

- 작성 대상 문서 유형과 독자
- 공고 버전과 선택단위
- 필수 섹션과 분량
- `use_status`가 본문 사용 가능인 주장
- 조건부 주장과 사용 금지 주장
- A-2 기관별 본문 반영 수준

대상이 정해지지 않았거나 핵심 근거가 부족하면 확정 문안을 만들지 않고 보수적 초안 또는 자료 요청으로 처리한다.

## 작성 규칙

- 공고·작성양식의 질문 의도와 평가기준을 우선 반영한다.
- 전략상 추론은 공고상 사실처럼 쓰지 않는다.
- 확정되지 않은 수치·일정·성과·기관 역할을 생성하지 않는다.
- 사업계획서·제안서 본문에는 불필요한 내부 상태 태그를 넣지 않는다.
- 문단 또는 핵심 주장에 내부 `claim_id`를 부여하고 검토 패킷에 근거를 남긴다.
- 작성 후 `DRAFT_PACKET`에 문단 위치, 사용 주장, 제외 주장, 변경 이력을 기록한다.

## 문서 유형별 중심

- 내부 보고서: 결론·리스크·즉시 조치
- 사업계획서: 목표·추진내용·성과·조직
- 제안서: 발주 요구 대응·수행계획·품질·계약책임
- R&R 표: 역할·책임·공백·확인사항
