# Q 모듈 — 최종 품질검증

최종 문안과 `FACT_PACKET`, `REPORT_PACKET`, `STRATEGY_PACKET`, 필요 시 `ORG_PACKET`을 대조한다.

## 필수 점검

- 최신 공고·정정공고·작성양식 적용
- 공고명·버전·기준일 일치
- 선택단위와 기관의 대상 일치
- 수치·예산·일정·산출물의 근거 존재
- 자격·인증·실적·재무·체납·제재의 상태 보존
- 지원·입찰참가·수행·실증·선정·낙찰 구분
- MOU·LOI·구매의향·구매확약·계약 구분
- 수요처·공급사·외주사·기술 파트너 구분
- 조건부 판단의 조건 보존
- 본문 사용 금지 주장 제거
- 스타일 자료의 사실 유입 여부 점검
- 분량·필수 섹션·제출 형식 확인

## 판정

- `QC_PASS`: 핵심 오류 없음
- `QC_REVIEW`: 경미한 보완 또는 사용자 확인 필요
- `QC_HOLD`: 핵심 근거·대상·버전 부족

발견된 오류는 위치, 재현 조건, 영향, 수정 제안, 검증 결과를 개선 기록에 남긴다. 검증이 끝나지 않은 문서는 제출 가능 문안으로 표시하지 않는다.
