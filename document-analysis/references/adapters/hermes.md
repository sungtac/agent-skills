# Hermes adapter

The bundled shell commands target Linux/WSL. Before use, confirm Hermes runs in a compatible environment, exposes terminal and filesystem access, and has the local processors installed. For general personal-document discovery, search the configured Drive connector first; if it has no relevant file or is unavailable, search local storage.

For a Drive document, save a local analysis copy in the user's Windows Downloads folder when that folder is mounted and writable. Otherwise ask for or report an available local destination. Keep the common scripts unchanged. This adapter may define only the runtime-specific file-provider method, output path presentation, and permission behavior.
