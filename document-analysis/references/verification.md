# Verification

Every analysis directory contains a manifest, extracted text, and a quality report. Verify source existence, source hash, processor exit status, output existence, and non-empty extraction where text is expected.

For material decisions, additionally compare page-level coverage from two processors or inspect rendered problem pages. A clean tool exit is not proof that the extracted text is accurate.

Report uncertainty precisely: inaccessible source, encrypted document, page-level OCR failure, garbled extraction, missing structural information, or a discrepancy between processors.
