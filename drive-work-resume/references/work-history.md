# Work history contract

The private session binding is created only after the exact direct-child task is resolved. The helper uses the host's `CODEX_SESSION_ID`; it does not invent an identity. Before switching away from a marked task, checkpoint it. Exact folder names may be used for unnumbered tasks; duplicate names or number prefixes are ambiguous. If a task is moved away from its original year folder, queued entries are retained rather than sent to an unverified destination.

Each checkpoint is a complete, concise current-state snapshot stored as a separate UTF-8 Markdown file in the selected task folder's `_업무기록` child. Its name is `YYYY-MM-DD_HHMMSS_microseconds_eventid.md` in Asia/Seoul time. Multiple events on a day remain separate; no mutable latest file or existing user document is overwritten. Newest filename is the current briefing. Fetch only the latest entry for a normal briefing, or select a date-inclusive range and read matching entries newest first. A bounded result reports truncation.

The local outbox is private (owner-only directory and files). It is written and fsynced before delivery. A host-local lock serializes outbox processing. Retrying uses the same event filename, verifies remote content, and removes the local entry only after verification. Existing mismatched contents or duplicate Drive names stop delivery for inspection. This provides retryable delivery; it is not a claim of global exactly-once delivery when different machines or Drive clients race. If Drive is unavailable after binding, the snapshot remains queued locally. Resume reports pending entries separately. Retrying checks that each bound task still belongs directly to the stored year before creating or writing its history folder.

The assistant is responsible for producing accurate summaries and avoiding secrets. Neither a prompt nor a regular Stop hook can capture work lost before a checkpoint, survive every abrupt process termination, or guarantee assistant compliance. A Stop reminder is not independent proof of a saved record. Report pending sync, ambiguity, or missing history rather than claiming success. Desktop connector support and other provider runtimes are separate and are not verified by the CLI helper.
